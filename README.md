# IP Messenger Pro — update feed

IP Messenger Pro for macOS checks `appcast.xml` in this repository once a day and offers new
versions to install. The update archives are attached to the [`updates`](../../releases/tag/updates)
release.

Every archive is signed. The app refuses any archive that is not signed with the project key.

To install by hand, download the newest `IPMessenger-<version>.zip` from the `updates` release,
unzip it and move `IPMessenger.app` to the Applications folder.
